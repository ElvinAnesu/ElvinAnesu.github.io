# elvinanesu.github.io

Public developer site for Elvin Kakomo. Hosts the Cops & Robbers privacy policy, terms, and `app-ads.txt`.

- Site: https://elvinanesu.github.io/
- Privacy: https://elvinanesu.github.io/cops-and-robbers/privacy.html
- Terms: https://elvinanesu.github.io/cops-and-robbers/terms.html
- app-ads.txt: https://elvinanesu.github.io/app-ads.txt

To replace the contact email later:

```bash
sed -i 's/CONTACT_EMAIL_PLACEHOLDER/you@example.com/g' index.html cops-and-robbers/privacy.html cops-and-robbers/terms.html
```
